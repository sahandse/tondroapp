# تندرو | صفحه دانلود

صفحه رسمی معرفی و دانلود تندرو، ساخته‌شده با TypeScript و Vite.

## مشاهده

https://sahandse.github.io/tondroapp/

## توسعه

```bash
npm install
npm run build
npm run dev
```

## انتشار

در Settings → Pages، قسمت Build and deployment را روی **GitHub Actions** قرار دهید. هر بار تغییر روی شاخه `main`، گردش کار `.github/workflows/deploy.yml` را برای ساخت و انتشار سایت اجرا می‌کند.

دکمه دانلود از انتشارهای رسمی مخزن [tondro](https://github.com/sahandse/tondro/releases) فایل APK را پیدا می‌کند. تا وقتی فایل APK منتشر نشده باشد، لینک صفحه انتشارها نمایش داده می‌شود.

نمای گوشی در سایت **مفهومی** است و اسکرین‌شات واقعی اپلیکیشن نیست.
